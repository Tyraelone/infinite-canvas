# 本机 AI 接入设计

用户已批准直接修改、补齐依赖、启动与实际生成验证。

## 目标

无限画布在本机可用：视频使用现有 MiniMax H3；生图可选 Qwen-Image-2.1、Codex；文本和创作助手可使用本机 Codex 登录态。生成结果进入原有画布节点并可播放、保存。

## 方案

采用本机 OpenAI 兼容接口层，复用 `D:\AI\MiniMax-H3\studio` 的成熟工作流和现有 8189 推理服务；不复制模型。视频通过现有 8190 工作室队列执行。Qwen 使用现有 API 图。Codex 通过本机 app-server 的 JSON RPC 调用，凭据由 Codex 自己读取。

单独配置 ComfyUI Bridge 也可生成本机媒体，但不能覆盖 Codex 生图，且需要额外配置工作流。重新编写整套推理引擎成本高且无法复用已有队列与验证成果，因此采用接口层。

## 接口与界面

- 前端保留既有模型选择和节点生成界面。启用本机模式时自动加入本机模型渠道，保留用户其他渠道。
- 网关提供 `/v1/models`、`/v1/images/generations`、`/v1/images/edits`、`/v1/videos`、`/v1/videos/{id}`、`/v1/chat/completions`，以及状态和结果文件接口。
- Codex 图像生成必须取得真实输出文件；模型文字声称已生成不算成功。
- 明确限制 H3 支持的分辨率、画幅、时长和参考图片；不静默丢弃用户设置。
- 提供中文说明、一键启动和按本项目进程身份停止入口。仅监听回环地址；不修改现有局域网配置。

## 实施选择

新增 Python aiohttp 网关，使用现有 embedded Python。Next.js 同源代理连接网关；Codex 使用独立临时会话，并限定工具权限。后端使用 8081，避免 Steam 已占用的 8080。前端 3000，网关 8191，保留 H3 8189、工作室 8190。

## 验收

接口契约与错误测试通过；前端构建通过；浏览器实际生成 Qwen 图片、Codex 图片和 H3 短视频，确认图片尺寸、视频解码和画布节点；通过 Codex 得到实际文本回复。已有运行任务只排队、不打断。
